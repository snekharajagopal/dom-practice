# JavaScript DOM and Events – Practice Exercises

## About This Repository

This repository contains my JavaScript practice exercises from HackGenix Day 9 and Day 10 training.

The exercises helped me understand how JavaScript interacts with HTML elements, changes webpage content, handles user actions, validates forms and stores data in the browser.

I completed the exercises in three levels: Basic, Intermediate and Advanced.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser localStorage
- Visual Studio Code
- Google Chrome DevTools
- Git and GitHub

## Level 1 – Basic

Practised basic DOM selection and manipulation.

### Concepts Learned

- `document.querySelector()`
- `document.querySelectorAll()`
- `textContent`
- `style`
- `classList.add()`
- `classList.remove()`
- `classList.toggle()`
- `addEventListener()`
- Input events

## Level 2 – Intermediate

Practised DOM manipulation, event handling and browser storage.

### Concepts Learned

- JavaScript arrays
- `createElement()`
- `append()`
- `addEventListener()`
- Form submit events
- `preventDefault()`
- Input validation
- `dataset`
- `nextElementSibling`
- `localStorage`
- `setItem()` and `getItem()`

## Level 3 – Advanced

Practised building interactive applications using DOM events, event delegation and localStorage.

### Concepts Learned

- Event bubbling
- Event delegation
- `event.target`
- `event.preventDefault()`
- `matches()` and `closest()`
- Form validation
- Regular expressions
- Callback functions
- Array methods
- JSON
- `JSON.stringify()`
- `JSON.parse()`
- Browser localStorage

## Key Learning Outcomes

Through these exercises, I learned how to:

- Select and update HTML elements using JavaScript.
- Respond to user actions and browser events.
- Create, add and remove HTML elements dynamically.
- Build interactive forms with validation.
- Use event delegation to handle dynamic elements.
- Store and retrieve data using localStorage.
- Build interactive applications using JavaScript.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required exercise folder.
4. Run the HTML file using Live Server or a browser.
5. Open Chrome DevTools to inspect the output and debug errors.
